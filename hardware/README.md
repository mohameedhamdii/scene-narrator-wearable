# Hardware Design Files

## Schematic & PCB

Place KiCad exports here:

- `schematic.pdf` — full wiring diagram
- `pcb_layout.pdf` — board layout

## Enclosure

3D print files go in `enclosure_stl/`:

- `chest_badge.stl` — chest-mount prototype (Option B)
- `glasses_clip.stl` — glasses-clip form factor (Option A)

## Pin Reference

See section 8 of `plan-03-scene-narrator.md` for ESP32-P4 GPIO assignments.

## Recommended Dev Board

- [ESP32-P4 Function EV Board](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32p4/index.html)
- OV2640 camera module with DVP interface
- MAX98357A I²S breakout
